# Çamaşır Makinesine Şiir Okuyan Robot

Bu depo, evrendeki en ciddi ev aleti sorununu çözer:
**Çamaşır makineleri yeterince şiir dinlemiyor.**

Yıllardır tamburlar döndü, köpükler yükseldi, çoraplar kayboldu.
Ama kimse onlara dörtlük okumadı. Bu utancı bitiriyoruz.

## Resmi Misyon Beyanı

1. Makineye hitap et.
2. Varoluşsal bir kıta oku.
3. Sıkma sesini alkış san.
4. Programı bitir, vicdanı yıka.

## Kurulum

Python 3 yeter. Başka hiçbir şey istemiyoruz. Bağımlılık da bir kir türüdür.

```bash
python3 siir_motoru.py
```

## Kullanım Senaryoları

- Gece 03:04'te yalnız ev aletleriyle konuşmak.
- Çamaşır gününü edebi bir törene çevirmek.
- Komşuya "ben normalim" demek ama içeride şiir çalıştırmak.

## Teknik Özellikler

| Özellik | Değer |
|---|---|
| Dil | Türkçe, ağırbaşlı absürt |
| Performans | 1200 devir alkış |
| Güvenlik | Kapak kilitli, anlam açık |
